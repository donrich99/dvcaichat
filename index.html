DVC AI Setup

Enter your API key to get started. You can get a free key from your provider's dashboard.

🔑 Get a Free Groq API Key:

  1. Go to console.groq.com and sign up / login
  2. Go to API Keys → Create API Key
  3. Copy the key that starts with gsk_
  4. Paste it above and click Launch!

✅ All 5 models (Compound AI, GPT-OSS 120B/20B, Qwen 3.6) use Groq as provider. One key works for all!

⚠️ Do NOT use OpenAI, Claude, or other provider keys — they won't work here.

💡 Paste multiple keys (one per line) — auto-switch when one is busy!

🔒 Key stored locally in your browser only. Never uploaded anywhere.
